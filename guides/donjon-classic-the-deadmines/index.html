Qu'est-ce qui change dans Mortemines ?

Ce donjon hérité de WoW Classic est référencé pour les niveaux 17–26, dans Marche de l'Ouest. Notre fichier signale les différences suivantes par rapport aux anciennes références :

  • Objets d’équipement et ensembles retravaillés pour Forever ; les caractéristiques proviennent du client bêta. Les tables ci-dessous sont des références Classic, pas des taux Forever.

Il s’agit de sources documentaires de bêta ; elles ne garantissent pas que chaque récompense soit actuellement disponible.
